## System
Two-stage **retrieve → rerank**: union of top-20 neighbours under 4 encoders (char TF-IDF, SBERT, ResNet-50, CLIP) → 16 pair features (5 cosines, pHash distance/equal/same-file, length ratio, word & number Jaccard, number conflict, min #words) → scorer (weighted fusion **or** `HistGradientBoostingClassifier`) → val-tuned threshold → optional symmetric / connected-component post-processing.
